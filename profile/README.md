## 🧠 Overview

Lively Wallpaper is a Windows application for using animated and interactive backgrounds on the desktop. It supports videos, GIFs, web pages, shaders, and other dynamic content, allowing users to customize the appearance of their Windows desktop.

The application is designed with performance in mind and can automatically pause wallpapers when applications or games are running in fullscreen mode.

## 🚀 Key Features

| Feature | Description |
|---|---|
| 🌌 Live Wallpapers | Use animated backgrounds on the Windows desktop |
| 🎥 Video Support | Set supported video files as desktop backgrounds |
| 🖼️ GIF Support | Use animated GIF files as wallpapers |
| 🌐 Web Wallpapers | Display interactive HTML and web-based content |
| 🎨 Customization | Adjust and personalize supported wallpaper properties |
| 🖥️ Multi-Monitor | Configure wallpapers across multiple connected displays |
| ⚡ Performance Options | Control wallpaper behavior while applications are running |
| 🎮 Fullscreen Detection | Automatically pause wallpapers during fullscreen applications |
| 🔊 Audio Visualization | Support wallpapers with audio-reactive visual effects |
| 🛠️ Wallpaper Library | Organize and manage your desktop backgrounds |

## 💻 System Requirements

- **Operating System:** Windows 10 / Windows 11
- **Processor:** Modern x64-compatible CPU
- **Memory:** 2 GB RAM or more
- **Graphics:** DirectX-compatible GPU
- **Storage:** Available disk space for the application and wallpaper files
- **Display:** Compatible monitor with standard Windows graphics support

## Additional Information for Windows Users

Lively Wallpaper can be configured to reduce resource usage when the computer is busy. Wallpapers may pause automatically when a fullscreen application or game is detected, helping keep system resources available for other tasks.

The application supports different types of animated content, including video, GIF, web-based wallpapers, and interactive scenes. Users can also configure wallpapers individually for connected displays and adjust behavior according to their desktop setup.

For users with multiple monitors, Lively Wallpaper provides options for managing different backgrounds and layouts across the Windows desktop.
